## Lab Title
K-Nearest Neighbors (KNN) and Radius Neighbors (RNN) Classification

## Purpose
The purpose of this lab was to compare the performance of KNN and Radius Neighbors classifiers using the Wine dataset from Scikit-Learn.

## Dataset
Wine Dataset from sklearn.datasets

## Key Findings
- Multiple K values were tested using KNN.
- Multiple radius values were tested using Radius Neighbors.
- Accuracy trends were visualized using line plots.
- The comparison demonstrated how neighborhood size influences classification performance.
